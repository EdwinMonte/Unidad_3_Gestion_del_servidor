# Tarea 3.3

Consultar docs/Reporte_Tarea_3_3.pdf para instalación, validación y limitaciones.
RAID 1: /dev/md/unidad3 sobre sdd y sde. Samba: Unidad3. CUPS: U3_PDF.
El instalador valida discos nuevos de 10 GiB; ajustar solo después de identificar el hardware.
Los datos anteriores de la unidad no deben formatearse de nuevo.
El cierre exitoso está en evidencias/cierre_3_3.log.
Los PDF de impresión y jobs_ipp.json respaldan la prueba desde Windows.
Los scripts continuar_impresion_3_3.sh y cerrar_3_3.sh conservan los pasos de recuperación del ensayo.
Las credenciales Samba se encuentran solo en /root/unidad3/samba.credentials y no se publican.
